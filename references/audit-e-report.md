# Audit ad per ad e report

## Quando il lavoro è finito

Ogni creatività valida fornita compare nell'account come ad in bozza, con link,
copy e setup corretti e coerenti con l'account. L'audit non è completo finché
tutti i controlli sotto non hanno un esito.

## Checklist per ogni ad

Esito per voce: `ok`, `anomalia` o `non verificato`.

| # | Controllo |
|---|---|
| 1 | Adset corretto |
| 2 | Stato bozza |
| 3 | Pagina Facebook e profilo Instagram corretti (nome e logo) |
| 4 | Nome unico, senza `- copy`; prodotto, versione e anno coerenti col media |
| 5 | Testo principale, headline, description, CTA come previsto |
| 6 | Website URL effettiva corretta per il prodotto |
| 7 | Source URL e altri campi ereditati: nessuno discordante, oppure segnalato |
| 8 | Media corretto in ogni gruppo di posizionamenti pertinente |
| 9 | Media usato solo da questa ad. Nessuna ad punta al file di un'altra |
| 10 | Nessun media correlato, nessun tag prodotto, nessun prodotto aggiunto |
| 11 | Solo Single image or video attivo |
| 12 | Nessun browser add-on non previsto |
| 13 | Enhancement uguali a quelli delle ads di riferimento |

## Controlli sull'insieme

- Inventario contro ads create nell'adset: stessi numeri.
- Nomi tutti diversi.
- Nessun file usato da due ads, salvo che l'inventario lo preveda.
- Ricarica delle ads corrette e ripetizione dei controlli che Meta può aver
  cambiato (formati, Source URL, enhancement).

L'anteprima corretta non prova tutti i posizionamenti. Un controllo non fatto è
`non verificato`.
