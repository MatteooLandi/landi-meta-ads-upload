# Studio dell'account

Sola lettura. Nessuna modifica finché lo studio non è finito e l'inventario non
è pronto.

## Cosa leggere

```
LEGGI la campagna: obiettivo, impostazioni a livello campagna
LEGGI più adset della campagna: ottimizzazione, attribuzione, pubblico, posizionamenti
LEGGI più ads pertinenti: nome, identità, copy, headline, description, CTA, URL, formati, enhancement
PREFERISCI ads dello stesso prodotto, campagna o adset di destinazione
```

Una sola ad non basta: un valore visto una volta può essere un caso isolato.

## Profilo dell'account

Compila in chat, una riga per voce, con la provenienza (`verificato` se letto
dall'account):

| Voce | Cosa ricavare |
|---|---|
| Naming | Struttura: anno, prodotto, versione, formato, copy, destinazione. Separatori e maiuscole |
| Pagina Facebook | Nome e logo |
| Profilo Instagram | Nome e logo |
| Obiettivo e ottimizzazione | Come sull'adset di riferimento |
| Pubblico e posizionamenti | Solo lettura. Non si cambiano (`dichiarato: Matteo`) |
| Tracciamento | Pixel, parametri URL, regole già in uso |
| CTA | Quella ricorrente |
| Destinazione | Tipo di pagina usata dalle ads (prodotto, collezione, landing) |
| Enhancement attivi | Elenco di quelli attivi nelle ads di riferimento |

## Naming

- Il nuovo naming si adatta all'account. Non si impone una convenzione
  universale.
- Se l'account ha un prefisso di anno, si applica quello richiesto dal caso
  (esempio: `[2026]`).
- Il suffisso `- copy` che Meta aggiunge duplicando va sempre tolto.

## Copy

```
IF Matteo ha dato un file di copy        THEN usa quello
ELSE IF Matteo ha indicato dove prenderli THEN leggi lì
ELSE usa il copy ricorrente più adatto tra le ads pertinenti dell'account
IF Matteo indica una variante precisa     THEN usa quella
IF il copy non è coerente con le creatività THEN STOP e chiedi
```

Headline e description si recuperano dalle ads di riferimento. La description si
adatta al prodotto quando serve.

## Identità

Pagina Facebook e profilo Instagram si scelgono verificando nome e logo del
brand. Un profilo selezionato con errore di accesso Meta si verifica dopo la
ricarica della pagina. Non si modificano i permessi dell'account per aggirare
l'errore (`dichiarato: Matteo`).

```
CHIEDI conferma a Matteo prima di creare

```
